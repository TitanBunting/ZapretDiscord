>
> Добавьте каталог с zapret в исключения антивируса либо отключите проверку PUA — потенциально нежелательных приложений. Если вы уверенно понимаете настройку исключений, лучше добавить необходимое исключение. В противном случае рекомендуется отключить детектирование PUA.

## ⚙️Установка и использование

1. Активируйте Безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию"
    * В Firefox откройте настройку "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Перейдите на [страницу последнего релиза](https://github.com/TitanBunting/zapret-discord-youtube/releases/latest) и скачайте архив zip/rar

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно пропустить

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы

5. Запустите необходимый файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления стратегии в автозапуск выберите **`service.bat`** -> `Install Service` -> *нужная стратегия*

## ℹ️Что делают основные файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую для себя**

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные инструменты:
  - <ins>**`Install Service`** — добавляет выбранную стратегию в автозапуск Windows (services.msc)</ins>
  - **`Remove Services`** — удаляет стратегию и WinDivert из служб
  - **`Check Status`** — показывает состояние обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** — включает или отключает обход для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** — меняет режим обработки сервисов, перечисленных в `ipset-all.txt`.  
  Этот параметр может пригодиться при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках отображается состояние:
    - `none` — IP-адреса не проходят проверку
    - `loaded` — IP проверяется на присутствие в списке
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включает или выключает автоматический поиск обновлений
  - **`Replace active fakes`** — заменяет выбранный активный fake на другой из каталога `bin`
  - **`Update IPSet List`** — загружает актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновляет hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** — выполняет проверку обновлений
  - **`Run Diagnostics`** — ищет распространённые причины неисправности zapret.  
  В конце диагностики можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного прекращения работы клиента
  - **`Run Tests`** — запускает проверку стратегий:
    - `Standard tests` — проверяет сайты из `utils/targets.txt`
    - `DPI checkers` — проверяет DPI у разных провайдеров, включая Cloudflare и Amazon

## ☑️Частые вопросы и решения

### После запуска `general*` ничего не изменилось

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход). Его можно увидеть на панели задач.  
Если winws.exe не запустился, обратитесь к [#522](https://github.com/TitanBunting/zapret-discord-youtube/issues/522)

### Подходящей стратегии нет
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере

Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - В появившейся папке откройте файл `hosts` текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте соединение ещё раз. Если результата нет, убедитесь, что изменения действительно записались

#### Работа не гарантируется. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/TitanBunting/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Обнаружение используемого метода может привести к тому, что ранее рабочая стратегия со временем перестанет действовать.
> Здесь собрано много вариантов обхода. Если ни один не подходит, создайте собственную стратегию на основе одной из имеющихся, изменив её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` откройте `Run Diagnostics` и проверьте, нет ли ошибок

- Проверьте, что адрес нужного ресурса присутствует в списке доменов или IP-адресов

- Испытайте другие варианты, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/TitanBunting/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и другие необходимые данные
- Перезагрузите устройство
- В `service.bat` выберите `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их, а в конце ответьте Y
- Удалите прежний каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/TitanBunting/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива через ПКМ. Если в правом нижнем углу есть флажок разблокировки, установите его, нажмите "Применить" и затем "ОК"
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы
- Запускайте разные скрипты `general` и проверяйте доступ к интернет-ресурсам. Если выбранная стратегия не работает, закройте программу через значок замка на панели задач и попробуйте следующую
- После нахождения рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение не работает при активном zapret

- Убедитесь, что в `service.bat` параметр `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Узнайте имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно противодействовать таким расширениям
- Переберите остальные стратегии, особенно если раньше доступ уже работал
- См. также [#251](https://github.com/TitanBunting/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- В `service.bat` откройте `Run Diagnostics` и очистите там кэш Discord
- Проверьте работу приложения Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если Discord не открывается и в браузере, по очереди испытайте все стратегии. Возможна ситуация, когда YouTube работает на одной стратегии, а Discord — нет
- См. также [#252](https://github.com/TitanBunting/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/TitanBunting/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Игры не работают

Игр существует много, поэтому проверить и исправить каждую из них невозможно.

Попробуйте универсальный порядок действий:
- обновите ipset через `service.bat` и включите `Game Filter`
- если этого недостаточно, дополнительно включите `ipset any`

Учитывайте, что режим `ipset any` может нарушить открытие большого количества сайтов. Не оставляйте его включённым постоянно. Вместо этого определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/TitanBunting/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Моей проблемы нет в списке

- Опишите её [здесь](https://github.com/TitanBunting/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Списки для обхода можно расширить вручную:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть присутствует в `ipset-all.txt`, но конкретный домен из неё фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые следует исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`

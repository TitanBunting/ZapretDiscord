> ### ЕСЛИ АНТИВИРУС РЕАГИРУЕТ НА WinDivert
> Антивирус может среагировать на WinDivert.  
> WinDivert перехватывает и фильтрует сетевой трафик и необходим для работы zapret.
> Этот инструмент могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты с повышенным риском или хакерские утилиты. В результате файл удаляется и помещается в карантин. Название обнаружения обязательно содержит `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. В Kaspersky, например, для этого используется настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При грамотной настройке исключений лучше добавить нужную папку в исключения. Если вы не уверены в своих действиях, рекомендуется отключить обнаружение PUA.

## ⚙️Установка и использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и вручную выберите поставщика, отличный от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", укажите режим "Персональный", затем выберите "Выбрать провайдера/поставщика" и вручную введите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может оказаться заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Получите zip- или rar-архив на [странице последнего релиза](https://github.com/TitanBunting/zapret-discord-youtube/releases/latest)

3. Откройте свойства скачанного архива и включите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно не выполнять

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Найти рабочую стратегию: **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`
    * Добавить стратегию в автозапуск: **`service.bat`** → `Install Service` → *выберите подходящую стратегию*

## ℹ️Что делают основные файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую именно для вашей сети**

- [**`service.bat`**](./service.bat) — автозапуск, проверка и дополнительные операции:
  - <ins>**`Install Service`** — установить выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — убрать стратегию и WinDivert из списка служб
  - **`Check Status`** — узнать состояние обхода и служб, включая запущенные при старте стратегии и WinDivert
  - **`Game Filter`** — изменить режим обхода для игр и прочих приложений, использующих UDP и TCP на портах выше 1023.  
  **После изменения настройки стратегию необходимо перезапустить.**  
  В скобках отображается её текущее состояние: включено или выключено.
  - **`IPSet Filter`** — выбрать режим обработки сервисов из `ipset-all.txt`.  
  Это может пригодиться при диагностике ресурса, который без zapret работает, а с ним — нет.  
  В скобках показывается текущий режим:
    - `none` — ни один IP не проверяется
    - `loaded` — проверяются IP на совпадение со списком
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или выключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить используемый fake на другой файл из каталога `bin`
  - **`Update IPSet List`** — скачать из репозитория актуальный `ipset-all.txt`
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — проверить типичные причины, из-за которых zapret не запускается или не работает.  
  В финале можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; иногда это возвращает работоспособность, если Discord неожиданно перестал открываться
  - **`Run Tests`** — запустить проверку стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare, Amazon и другие


## ☑️Частые вопросы и неисправности

### После запуска `general*` не видно результата

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/TitanBunting/zapret-discord-youtube/issues/522)

### Подходящей стратегии нет
- Откройте командную строку с правами администратора
- Выполните по очереди следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если имеющийся hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте полностью содержимое открывшегося блокнота
  - Откройте файл `hosts` в созданной папке текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и повторите подключение. Если результата нет, проверьте, что hosts действительно был сохранён.

#### Результат не гарантируется. Если инструкция не помогла, используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/TitanBunting/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или снова перестал работать

> [!IMPORTANT]
> **Любая стратегия со временем может потерять работоспособность.**
> Вариант, который некоторое время работал, может перестать работать после обнаружения его параметров.
> Здесь собрано много стратегий обхода. Если ни одна не подходит, создайте новую на основе одной из существующих и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте результаты `service.bat` → `Run Diagnostics` и устраните найденные ошибки

- Убедитесь, что нужный адрес присутствует в списках доменов или IP

- По очереди проверьте другие варианты, включая **`ALT`**, **`FAKE`** и остальные стратегии

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/TitanBunting/zapret-discord-youtube/issues/765)

### Полная переустановка или обновление
- Сначала сохраните добавленные вами ресурсы и другие данные
- Перезапустите устройство
- Откройте `service.bat` → `Remove Services`
- Запустите `service.bat` → `Run Diagnostics`; при наличии ошибок исправьте их и в конце подтвердите действие клавишей Y
- Удалите каталог zapret
- Скачайте свежий архив `zapret-discord-youtube-...` [со страницы релизов](https://github.com/TitanBunting/zapret-discord-youtube/releases)
- Нажмите правой кнопкой по архиву и откройте свойства. Если в правом нижнем углу есть флажок разблокировки, включите его, нажмите «Применить» и «ОК»
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелов и специальных символов
- Запускайте разные `general`-скрипты и проверяйте нужные интернет-ресурсы. Если вариант не работает, закройте программу через значок замка на панели задач и попробуйте следующую стратегию
- После выбора рабочего варианта установите его в автозапуск: `service.bat` → `Install Service` → выберите нужную стратегию

### Игра или приложение не работает при включённом zapret

- Проверьте в service.bat, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может повлиять на ресурсы, которые вы не собирались обходить.

### Античит сообщает о WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё отображается среди служб

1. Определите имя службы командой в командной строке Windows, открытой через Win+R → `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её, подставив полученное имя в обе команды:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, включён ли [Secure DNS](#%EF%B8%8Fустановка-и-использование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться
- Переберите остальные стратегии, особенно если раньше всё работало
- См. также [#251](https://github.com/TitanBunting/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fустановка-и-использование) настроен
- Сначала определите стратегию, на которой открывается YouTube, и запустите её
- В `service.bat` перейдите в `Run Diagnostics` и очистите там кэш Discord
- Проверьте, заработало ли приложение Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если Discord не открывается и в браузере, снова протестируйте все стратегии. Случается, что YouTube работает на одной стратегии, а Discord — нет
- Дополнительные сведения: [#252](https://github.com/TitanBunting/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/TitanBunting/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую из них отдельно невозможно.

Попробуйте универсальный порядок действий:
- в `service.bat` обновите ipset и активируйте `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Учтите: режим `ipset any` может нарушить открытие большого числа сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/TitanBunting/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

- Опишите её [здесь](https://github.com/TitanBunting/zapret-discord-youtube/issues)

## 🗒️Как добавить адреса других ресурсов

Списки обхода можно расширять вручную:
- домены добавляются в **`list-general-user.txt`**; поддомены учитываются автоматически
- домены, которые нужно исключить, указываются в **`list-exclude-user.txt`**. Это полезно, например, когда IP сети есть в `ipset-all.txt`, но конкретный домен из этой сети фильтровать не нужно
- IP-адреса и подсети записываются в **`ipset-all.txt`**
- исключаемые IP-адреса и подсети добавляются в **`ipset-exclude-user.txt`**
  - Файлы **`*-user.txt`** будут автоматически созданы при первом запуске `zapret` или `service.bat`
